怎么工作

四个角色，各干一件事

你只管说和拍板；它管登记、派工、跟踪；产品只管把活干好。

你说一句话
→
负责人登记 · 派工 · 催办
→
任务账本状态 · 证据 · 历史
→
ZCode真正把活干完

改完的结果沿着同一条线回来，变成账本里的一条记录，再变成一句向你汇报的话。

任务的走法

五步，人只出场两次

  1. 你说一句原话入库，不改写。重复说会合并，不会多出一条。
  2. 它立项写清目标、预期结果、验收标准——这三样缺一样就不许往下走。
  3. 它派工建会话、指定工作区，任务进入执行中。
  4. 它跟踪只在卡住、要你选、或干完了这三件事上找你。
  5. 你验收每条标准都有证据才给你看；你说通过，才算完成。
只有你能说"完成"。它最多推到"待验收"。
